## What It Is:
That One Friend is a renpy based visual novel game. You're a character in a game who's main objective is to figure out a girl you see in your dreams. The characters around you hint about knowing her but when you ask them directly about her bad.. very bad things happen..

## Why I Made It:
I'm new to game designing so my main reason of making this was to get a hold of renpy, how it works and the syntax of the engine overall. The story is entire canon and I needed some place to deploy my thoughts.

## How I Made It:
**Tech Stack:**
- Ren'Py

This project was made with RenPy and VS code as the primary editor. The entire story is Canon and the images are open source images I scraped off the internet.

## What I Struggled With and what I learned:
Being the first project I ever made on Ren'Py, I learned a lot about the game engine and the syntax it uses. The syntax was overall similar to python which I was familiar with so I had no problems there. The part I most struggled with was the jump/goto tabling system. I later decided to scrap that idea and go for a messy block of code. I do plan on fixing this soon as the debugging is currently taking a lot of time right now. Overall, the process of writing the code for the game was fun and I really enjoyed it. 10/10 would do it again.
